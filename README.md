# 2026 송년회 게임존

회사 송년회용 QR 웹 게임. 로그인 없이 익명으로 입장하고, 사회자(MC) 화면에서 라운드를 열면 참가자 폰에 실시간으로 떨어집니다.

## 게임 5종
- 🎰 777 럭키 슬롯 (운빨)
- 🎡 행운의 돌림판 (운빨, 항목·비율 편집)
- ⏱️ 7.77초 블라인드 스톱워치 (감각)
- 🧠 송년회 스피드 퀴즈 (기본 34문제, 회사 맞춤 문제 추가·수정·JSON 백업, 개인전/라이브)
- 👀 눈치 게임 (평균의 2/3 · 겹치지 않는 숫자, AI 봇 대결/라이브 집계)

## 진행 방법
1. 참가자: QR을 찍으면 바로 입장. 이름은 익명으로 자동 배정되고 바꿀 수 있음.
2. 사회자: `#/mc` → PIN `2026` (변경 가능) → 큰 QR을 띄우고 라운드 시작.
3. 네트워크에서 실시간 소켓이 막히면: 각자 개인전으로 진행하고, MC의 `문제팩 링크 복사`로 문제 세트를 공유.

## 실시간
- 공개 MQTT 브로커 3곳(EMQX / HiveMQ / Mosquitto)에 WSS로 연결, 실패 시 자동 전환.
- 같은 기기 탭끼리는 BroadcastChannel로도 동기화.
- 실시간 연결이 없어도 모든 게임은 개인 플레이로 동작.
